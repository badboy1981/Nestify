# 🏗️ Project Generation (`nestify init`)

The `init` command is Nestify's scaffolding engine. It reads a JSON layout blueprint and physically creates the entire directory and file hierarchy on your file system. 

It can be used with embedded project presets or with JSON reports generated by `nestify scan` to instantly clone directory architectures.

---

## 🛠️ Usage & Options

```bash
nestify init [options]

```

### Flags & Options

| Flag | Short | Description | Default |
| --- | --- | --- | --- |
| `--template` | `-t` | Path to the JSON structure template or blueprint file. | **Required** |
| `--path` | `-p` | Target destination folder where the structure should be scaffolded. | `.` (Current Directory) |

!!! info "Cross-Platform & Shell Agnostic"
    Nestify is compiled into a single native binary with zero external dependencies. All CLI commands run identically across **Windows (PowerShell / CMD)**, **macOS**, and **Linux (Bash / Zsh)**. Learn more about [Shell Agnostic Execution](https://www.google.com/search?q=../getting-started/quickstart.md%23cross-platform-execution).

## 💡 Examples & Common Use Cases

### 1. Bootstrap Project from Embedded/Local Template

Scaffolds a standard Go project structure into a target directory (`./MyNewApp`):

```bash
nestify init --template templates-projects/go_standard.json --path ./MyNewApp

```

### 2. Architectural Reverse-Engineering (Scaffold from Existing Scan)

Recreate an empty directory layout blueprint captured from a scanned GitHub repository or existing project:

```bash
# Step 1: Scan an existing project folder-only
nestify scan --path ./ExistingApp --folders-only

# Step 2: Use the generated JSON report to create a brand new empty clone
nestify init --template Nestify-Report/ExistingApp_20260805_010000.json --path ./NewCleanApp

```

## 📋 JSON Template Structure Format

The `init` command parses JSON blueprints built as nested node trees. Each object specifies a `name`, a `type` (`"folder"` or `"file"`), and an optional list of `children` nodes.

### Example JSON Blueprint (`go_basic.json`):

```json
[
  {
    "name": "cmd",
    "type": "folder",
    "children": [
      {
        "name": "app",
        "type": "folder",
        "children": [
          {
            "name": "main.go",
            "type": "file"
          }
        ]
      }
    ]
  },
  {
    "name": "internal",
    "type": "folder",
    "children": [
      {
        "name": "config",
        "type": "folder"
      }
    ]
  },
  {
    "name": "README.md",
    "type": "file"
  }
]
```

## ⚙️ How Generation Works

1. **Path Normalization:** Nestify automatically normalizes OS-specific path slashes (`/` vs `\`) for seamless cross-platform execution.
2. **Recursive Directory Creation:** It creates parent folders first before generating nested subdirectories or empty placeholder files.
3. **Safe Execution:** Existing files are preserved unless overwritten, preventing accidental data loss during scaffolding.

??? tip "Creating Custom Templates"
    You can create your own custom JSON blueprints manually or save `nestify scan` outputs to build a library of reusable organization templates.
