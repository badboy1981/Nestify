    🛠️ Custom Scaffolding & Project Templates

    Project templates are JSON blueprints under templates-projects/.
    nestify init reads a blueprint and creates the physical folders and files on disk (including optional file content).

    This is different from nestify copy, which clones a live project while respecting .nestifyignore.

    🏗️ Built-in project templates

    File Description
    go_basic.json Minimal Go layout (cmd/main.go, internal/)
    go_standard.json Standard-style Go layout (cmd, internal layers, pkg, configs, …)
    mkdocs_scaffold.json Documentation site skeleton for MkDocs-style docs/ trees

    Paths are relative to the Nestify source tree when you clone the repo. After install, you can still point --template at any JSON file on disk (including scan exports under Nestify-Report/).

    🛠️ Usage

    nestify init --template <path-to-json> --path <destination>
    Flag Description
    --template JSON blueprint path
    --path Where to create the structure (default .)

    Example with an embedded-style path from a local clone:

    nestify init --template templates-projects/go_standard.json --path ./MyNewApp

    CLI reference: Init command.

    📋 JSON shape

    init unmarshals into the project Template type. The important field is root: a tree of nodes.

    Each node:

    Field Meaning
    name File or folder name
    type "folder" or "file"
    content Optional string written into files (empty → empty file)
    children Nested nodes (folders)

    Example (simplified from go_basic.json):

    {
  "name": "GoBasicProject",
  "root": [
    {
      "name": "cmd",
      "type": "folder",
      "children": [
        {
          "name": "main.go",
          "type": "file",
          "content": "package main\n\nimport \"fmt\"\n\nfunc main() {\n\tfmt.Println(\"Generated by Nestify!\")\n}"
        }
      ]
    },
    {
      "name": "internal",
      "type": "folder"
    }
  ]
}

    mkdocs_scaffold.json also sets projectType, language, and tags metadata fields.

    🔄 Scaffold from a live project (structure only)

    1. Scan folders only:
    nestify scan --folders-only
    1. Use the generated JSON under Nestify-Report/ as --template:
    nestify init --template Nestify-Report/YourProject_TIMESTAMP.json --path ./NewEmptyClone

    This recreates structure (and empty files unless the JSON carries content). For a full clean copy with real file bytes, use nestify copy instead.

    ➕ Add your own project template

    1. Author a JSON file following the node tree format above.
    2. Optionally place it in templates-projects/ inside a Nestify clone.
    3. Run init with --template pointing at that file.
    4. If you want it embedded for distribution, keep it under templates-projects/ and reinstall with go install ./cmd/nestify (same embed pattern as ignore/prompt templates).

    ⚖️ init vs copy

    init copy
    Input JSON blueprint Live directory (cwd)
    Output Scaffolded tree from template Real files streamed to --path
    Filter Defined by JSON .nestifyignore
    Best for New empty/skeleton projects Clean clone of an existing repo
