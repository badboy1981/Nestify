    💬 AI Context Generation (nestify context)

    The context command is Nestify's primary tool for Prompt Engineering and LLM Contextualization. It merges project metrics, source code language breakdowns, and directory tree representations into a single, unified Markdown file (Nestify-Report/ai_context_report.md).

    Additionally, it allows developers to inject pre-built or custom prompt instructions directly into the top of the report, making it instantly ready to send to LLMs like ChatGPT, Claude, or Gemini.

    🛠️ Usage & Options

    nestify context [options]

    Flags & Options

    Flag Short Description Default
    --prompt -p Injects an embedded prompt template (e.g. architecture, refactor, security) or raw instruction text into the report header. "" (None)
    --depth -d Limits directory tree traversal depth (0 for unlimited). 0
    --path Target directory path to process. . (Current Directory)

    Cross-Platform & Shell Agnostic

    Nestify is compiled into a single native binary with zero external dependencies. All CLI commands run identically across Windows (PowerShell / CMD), macOS, and Linux (Bash / Zsh). Learn more about Shell Agnostic Execution.

    🔍 Discovering & Inspecting Prompt Templates

    Before injecting a prompt template into nestify context, you can discover available presets or preview their exact text using the built-in prompt management tools:

    • List all embedded prompt templates: 

      nestify prompt-list

    • Inspect a specific prompt's instruction text: 

      nestify prompt architecture

    For full details on using and customizing prompt instructions, check out the Prompt Management Guide.

    💡 Examples & Common Use Cases

    1. Generate Standard AI Context (No Injected Prompt)

    Scans the current project, analyzes language breakdown, builds the folder tree, and exports ai_context_report.md.

    nestify context

    2. Inject Built-in Prompt Template with Depth Restriction

    Uses the embedded architecture prompt template and restricts tree depth to 3 levels deep.

    nestify context -p architecture -d 3

    (Available embedded prompts can be discovered using nestify prompt-list).

    3. Inject Custom Prompt Text Directly

    Passes a custom task instruction directly from your terminal CLI session:

    nestify context -p "Review this codebase structure for Go clean architecture guidelines" -d 3

    🤖 Prompt Processing Resolution Order

    When you use the -p or --prompt flag, Nestify resolves the prompt input using the following logic:

    1. Embedded Template Match: It checks whether the string matches an embedded template file inside templates-prompts/ (e.g., refactor, security, architecture)[cite: 6]. If a match is found, the template's file content is injected[cite: 6].
    2. Raw Text Fallback: If no template name matches the provided argument, Nestify treats the input as raw custom prompt text and injects it as-is into the header[cite: 6].
